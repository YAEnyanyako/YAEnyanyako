# AIプロダクト作品集 / AI Product Portfolio

要件定義・情報設計・受け入れ確認・改善の優先順位付けを担当しています。コードはAIコーディングツールで生成しています。

I own requirements, information design, acceptance review and prioritization. Code was generated with AI coding tools.

## Projects

- **[Shukatsu OS](https://yaenyanyako.github.io/shukatsu-os-showcase/)** — 散らばった就活の通知を会社・募集ごとに整理し、根拠つきで「次にやること」を示すツール。 / Turns scattered job-search notices into per-company, per-opening next actions, with the evidence attached.
- **[Kotobacho](https://github.com/YAEnyanyako/kotobacho)** — 動画から教材と出典付き単語帳を作る。 / Video lessons and vocabulary linked to source scenes.

公開デモ・画面には架空のサンプルを使用し、個人プロフィールや私用の利用件数は掲載しません。 / Public demos and screens use fictional samples; personal profiles and private usage counts are not published here.
