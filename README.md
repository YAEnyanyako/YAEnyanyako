# Project Showcase / プロジェクト紹介

Interactive tools for organizing information and learning from Japanese videos.
情報整理と日本語動画学習のためのツールを紹介します。

## Projects

- **[Shukatsu OS](https://yaenyanyako.github.io/shukatsu-os-showcase/)** — Company and project workspaces for messages, deadlines, research, and preparation. The public demo uses fictional data; external actions are simulated.
- **[Kotobacho](https://github.com/YAEnyanyako/kotobacho)** — A local-first Japanese video learning tool with lessons and vocabulary linked to source scenes. Public screenshots use fictional examples.
