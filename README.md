# AI Product Portfolio / AIプロダクト作品集

実際に使いながら改善してきた2つのAI支援プロジェクトです。**私は要件定義、情報設計、受け入れ確認、改善判断を担当しました。** コード生成にはAIコーディングツールを使用しています。

Two projects developed and refined through real use. **I owned requirements, information design, acceptance review, and iteration decisions.** Code was generated with AI coding tools.

## Projects

- **[Shukatsu OS](https://yaenyanyako.github.io/shukatsu-os-showcase/)** — 企業研究・経験談蒸留・ES改善・面接準備を、会社／募集ごとの締切と行動につなげる。215件のメッセージと、166社・243件の募集／イベントを管理。 / Connects research, selection-experience distillation, ES revision and interview prep to company/project actions, with 215 message records and 243 opportunities across 166 companies.
- **[Kotobacho](https://github.com/YAEnyanyako/kotobacho)** — 動画から教材と出典付き単語帳を作る。前身の学習フローで8動画・147語を記録。 / Video lessons and vocabulary linked to source scenes; 8 videos and 147 words recorded in the predecessor learning workflow.

*本人1名の利用記録、2026年9月27日集計。公開画面には架空データを使用。 / Single-user records audited Sep 27, 2026. Public screens use fictional data.*
